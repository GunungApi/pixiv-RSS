# スケジューラーMVP

Google フォーム + スプレッドシート + Apps Script を用いた面談スケジューラーの最小実装です。

## 機能
- 親用フォーム: 家ごとのトークン、生徒名、候補日時、備考を入力。
- 承認画面: Web アプリで未承認候補を一覧表示し、複数候補を一括承認。
- 承認時:
  - Google カレンダーにイベント作成（移動バッファ付き、競合チェック）。
  - 親をゲスト招待し、24 時間前と 2 時間前にリマインド。
  - 確定メール送信。メール内リンクから変更・キャンセル可能。
  - 操作を監査ログとして保存。
- 設定値はスプレッドシートの「設定」シートで編集可能。

## セットアップ手順
1. Google スプレッドシートを作成し、このリポジトリの `Code.gs` と `approve.html` をコンテナバインドスクリプトとして貼り付ける。
2. スクリプトエディタで `setup()` を実行するとフォームと必要なシートが自動作成される。
3. `設定` シートにカレンダー ID やリマインド時間などの値を入力する。
4. スクリプトを Web アプリとしてデプロイし、承認者用 URL を共有する。
5. フォーム URL を保護者へ配布する。トークンは各家庭へ個別に知らせる。
6. 月初にフォームの候補日を更新し、受付期間を調整する。

## 変更・キャンセル
確定メール内のリンクから再度フォームに回答し、承認後にイベントが更新/削除されます。

## 注意
- タイムゾーンは `Asia/Tokyo` を前提としています。
- 本リポジトリはコード例のみを提供し、実際のデプロイは Google Apps Script 上で行ってください。
